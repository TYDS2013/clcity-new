关于翠林城

翠林城是一座在《我的世界》中由玩家共同建设的城市，以“绿色、宜居、有序”为规划理念，分为中央公园区、轨道交通沿线居住区、市民服务区与东部产业区。

本站用途

  1. 发布城市要闻（独立“要闻”页面）
  2. 提供城市建设相关的服务入口（“服务”页面）
  3. 通过飞书表单收集意见，并支持查询处理进度（“反馈”页面）

文章发布说明

要闻文章不再分散存放在各个页面中，而是统一放在 post 文件夹。新增文章时：

  1. 将 .md 文件放入 post/
  2. 在 post/posts.json 的 posts 数组中登记文件名
  3. 首页“最新要闻”与独立“要闻”页会自动读取，无需修改 HTML

反馈数据说明

反馈表单与处理情况查询均直接嵌入飞书托管页面，数据保存在飞书多维表格中。纯静态托管下不适宜在前端直接调用飞书 API 读取记录，因为 tenant_access_token 的获取需要 App Secret，而密钥不能暴露在前端代码中。飞书多维表格自带的查询页面支持匿名查询，是在 GitHub Pages 上展示处理进度最直接的方式[reference:2]。

本站为玩家自建非商业站点，与 Mojang Studios 及微软无关。
